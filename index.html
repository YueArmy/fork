        このアプリの仕組み（解説）

        SNSを開いた瞬間に割り込み、2つの未来のイラストで分岐を出す。考え方は「一瞬の衝動への鎮痛剤（頓服）」：長期的な矯正ではなく、その回の衝動をやり過ごす。分岐の絵は『スイッチ！』の「目的地の絵はがき」と、未来の場面を具体的に思い浮かべると衝動的な選択が弱まるという研究（エピソード未来思考）が土台。選択肢の言葉は「習慣を身につける」ためでなく、「どんな人でいるか」（アイデンティティ）で書く。

        前進カウントと数字の目安（解説）

        カウントは0から始まらない。アプリを入れた時点で+1、設定を完了した時点で+1（合計2）。これはスタンプカードの研究（最初から2つ押してあるカードは完遂率が高い＝授与進捗効果）に基づく。ゲージの目安（18回・66回・254回）は、習慣が自動化するまでの期間を測った研究（Lally ら, 2010：中央値66日、幅18〜254日）の数字を回数に読み替えたもので、卒業ラインではない。表示は「残り」ではなく「溜まった分」を見る形にしてある。

        実機への置き方（iPhone / ショートカット）

        1. このページを Safari で開き、共有ボタンから「ホーム画面に追加」する。
        2. ショートカット App → オートメーション → ＋ → 「App」を選ぶ。
        3. 対象のSNS（Xなど）を選び、「開かれている」をチェック、「すぐに実行」を選ぶ。
        4. アクションに「URLを開く」を追加し、設定画面で作れる 設定リンク（?auto=1 と今の設定が全部入ったURL）を貼る。開くたびに設定が適用されるので確実。設定を変えたらリンクも貼り直す。
        5. SNSを開くたびに分岐画面が先に出るようになる。効きすぎ／弱すぎを感じたら、設定で服用の長さを変える。

        注意：オートメーションの挙動はiOSのバージョンで変わる。まず1つのアプリだけで試して、ループ（開く→分岐→開く…）にならないか確認すること。分岐でSNS側を選んだあとは、このページを経由せず直接開くのでループにはならない想定。

        分岐の言葉の作り方：目標は「新しい習慣を身につける」じゃなく、「どんな人でいるか」で書く（設定で変更できる）。1回の選択は小さくても、いい方向に進めた回数はブライトスポットとして貯まっていく、という考え方（『スイッチ！』）。

        実現方式の正直な限界（調査済み）

        1. ショートカット方式：割り込みは「起動の前」ではなく「起動の直後」。Xの画面が約1秒チラッと見えてから、この画面に切り替わる。フルのUIは出せるが、完全な先回りはできない。
        2. ループ問題：分岐でSNS側を選んでXを開くと、オートメーションが再び発火して分岐に戻される。これを避けるには「さっき分岐を通った」という合図（バイパス）が必要で、one sec は自アプリの中でそれを管理している。Webページ単体では持ちにくいので、製品化するならネイティブアプリ＋オートメーションが本命の形。
        3. Screen Time APIの遮断画面：起動前に止められる唯一の方式だが、出せるのはシステムの遮断画面（文言＋ボタン最大2つ）だけ。イラスト2択もタスクも出せないし、Kindleを開くこともできない。
        4. Android：アプリ起動の検知＋全画面オーバーレイが許可制で使えるので、この設計のまま（起動とほぼ同時にフルUI）実現できる。
